In-Browser Search Architecture & Models

Everything runs 100% locally inside your browser (Web Worker + WebGPU / WASM via @huggingface/transformers v4) across all 39,472 canonical products (with an optional Hide Deprecated / Superseded filter in More Filters removing 622 superseded/obsolete editions, matching the Catalogue Viewer).

  • Instant 3-Field EO BM25 (3.1 MB): Exact lossless port of the DuckDB FTS BM25 engine (title 2.5×, keywords 1.5×, body 1.0×, EO chemistry/orthography normalization, Snowball Porter stemmer, exact 571 stopwords) — verified 0.00 score divergence against Python.
  • Semantic Hybrid (EmbeddingGemma 2 · 512-d · Apache-2.0): Loads only the 270M text encoder (q4, ~175 MB) from onnx-community/embeddinggemma-2-ONNX plus 512-d Matryoshka per-row int8 document vectors (15 MB), fused with BM25 via RRF (w_dense=1.0, w_bm25=0.6, k=60).
  • Optional Stage-2 Reranker (Qwen3-Reranker-0.6B-ONNX · Apache-2.0): Strictly opt-in (~995 MB q4 from Hugging Face). Scores Stage-1 candidates sequentially using log-odds margins (yes - no) blended with Stage-1 RRF (0.4 / 1.0, k=30). Slower (especially without WebGPU), but yields stronger Top-10 ranking precision (78.12% Fam-nDCG@10 / 100% Hit@10 on the 60-query policy holdout).
  • Verified Hard Limits & Family Collapse: Mirrors exact Python guards — verified output-grid sources, exact 1.0× grid cutoffs, full-global footprints, documented end-years, and sensor/variable/layer-role/cadence/DOI family collapsing.

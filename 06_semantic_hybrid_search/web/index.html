Retrieval Method & Local API

Queries run locally against the 39,474 canonical L3/L4 records (38,852 active after excluding superseded/obsolete releases):

  • Stage 1 (Hybrid RRF): Combines 768-d dense embeddings (EmbeddingGemma-2 BF16) and deterministic single-threaded DuckDB EO-normalized multi-field BM25 via weighted Reciprocal Rank Fusion (k=60, weights 1.0 / 0.6).
  • Null-Safe Filtering & Mirror Collapsing: Because ~70% of upstream records omit structured grid or level fields, null-safe mode keeps unlabelled candidates so Stage 2 can judge them from their descriptions. Generic title-stem + cosine collapsing (cos ≥ 0.94, guarded against merging distinct orbital sensors) deduplicates cross-platform mirrors and annual editions.
  • Stage 2 (Reranking): Rescores the top 50 collapsed families using jina-reranker-v3.5 (CC BY-NC 4.0, highest accuracy) or Qwen3-Reranker-0.6B (Apache-2.0, permissive license), blended with Stage-1 rank (0.4 / 1.0, k=30). The first reranked query lazy-loads the model into accelerator or CPU memory; subsequent queries stay warm.
  • Device-Agnostic Backend: Automatically selects native MLX on Apple Silicon (mlx-community/embeddinggemma-2-bf16, jina-reranker-v3.5-mlx), PyTorch on NVIDIA CUDA, or PyTorch CPU when no GPU is detected (google/embeddinggemma-2, jina-reranker-v3.5, Qwen3-Reranker-0.6B).
  • REST & CLI Client: Query this server programmatically at POST /api/search, POST /api/export, GET /api/product/{record_id}, or via uv run 06_semantic_hybrid_search/04_search_cli.py --server http://127.0.0.1:8080 -q "...".

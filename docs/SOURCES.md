# Source Registry, Access Points & L3/L4 Harmonization Architecture

This reference documents the **35 primary and federated Earth Observation (EO) metadata sources** harvested into the catalogue (`34` EO product catalogues + `1` WMO OSCAR/Space reference taxonomy), along with the deterministic processing-level ontology, institutional attribution rules, and evaluated scope boundaries.

---

## 1. Processing-Level Ontology & Inclusion Criteria

| Processing Level / Class | Definition | Catalogue Disposition | Key Rules & Boundary Handling |
| :--- | :--- | :--- | :--- |
| **Level 0 (L0)** & **RDR** | Unprocessed instrument telemetry, Raw Data Records, and packet streams. | **Excluded** | Logged in `02_preparation/data/excluded_records_log.parquet`. |
| **Level 1 (L1 / L1A / L1B / L1C / L1G / L1R / L1T)**, **TDR/SDR**, **Aerial Orthophotos** | Radiometrically/geometrically calibrated TOA radiances, brightness temperatures, SAR SLC/GRD swaths, and airborne orthophoto programs (e.g., NAIP, DOQ, NRCan NAPL, European DOPs). | **Excluded** | Excluded uniformly across agency archives and cloud mirrors (`raw scenes`, `TOA`, `OLCI`, `AVNIR-2/ORI`, `SPOT World Heritage L1`, `ccm-*`). |
| **Level 2 (L2 / L2A / L2B / L2G / L2P)** | Geophysical retrievals in sensor swath/orbit/scene geometry, uncomposited scene/tile surface reflectance, scene-level cloud probability, or instantaneous L2 event streams (e.g., S2 L2A, S2 Cloud Probability, S5P L2, MTG FCI Active Fire L2, MODIS `09GA`/`09GQ`, `L2P` swaths). | **Excluded** | Multi-level collections whose upstream metadata bundles `L2` together with `L3`/`L4` deliverables, as well as gridded composites labelled L2 upstream (e.g., S3 SYNERGY 1-/10-day syntheses, GCOM-C L2 statistics composites), are retained at collection granularity. |
| **Gridded L3 ARD Reflectance (`L3_ARD_REFLECTANCE`)** | Spatio-temporally composited/gridded surface reflectance mosaics (e.g., NASA `HLSL30`/`HLSS30`, CLMS `Sentinel-2 Global Mosaic`, DE Africa/Pacific `GeoMAD`, NRCan `RCM ARD Mosaic`, MODIS `09A1`/`09Q1`/`09CMG`). | **Included (Tagged Subtype)** | Tagged symmetrically as `L3_ARD_REFLECTANCE` (`eo_ard_surface_reflectance_mosaic`) regardless of provider pool. |
| **Level 3 (`L3` / `L3_THEMATIC_BIOPHYSICAL`)** | Geophysical variables, thematic maps, and DEMs mapped onto uniform space-time grids (e.g., NDVI, LAI, SST, land cover, forest change, GHSL, TMF, GSWE, DEMs). | **Included (`L3`)** | Retains non-sensor thematic hierarchies (`FAO WaPOR L1/L2/L3`, `GAUL Admin Level 0/1/2`, `Water Level v2`) cleanly. |
| **Level 4 (`L4` / `eo_reanalysis_or_model`)** | Multi-sensor gap-filled analyses, data-assimilated reanalyses, inversions, and EO-driven models (e.g., OSTIA SST, ERA5, CAMS EAC4, GloFAS, GEDI L4B, GLEAM4). | **Included (`L4`)** | Distinguishes `operational_ongoing_series`, `completed_or_mission_bounded_release` (single-epoch maps, static DEMs, mission-bounded releases), `research_or_benchmark_release`, `planned_or_preoperational`, `deprecated_or_superseded`, and `unknown` entries. |
| **Sensitivity Boundary Classes** (`strict_eo_c1_eligible = False`) | EO-constrained hybrid socio-environmental models (`GHSL` population, `OpenLandMap`, `iSDAsoil`, `WorldPop`), gridded in-situ interpolations (`E-OBS`, `CMEMS INSITU OA`), bottom-up inventories (`EDGAR`, `CEDS`, `FAO GLEAM3`), and authoritative geometries (`WDPA`, `WDOECM`, `Natura 2000`). | **Included (Flagged)** | Discrete station/buoy/plot logs are excluded in `02_preparation`; gridded sensitivity and boundary datasets remain traceable without contaminating strict-EO counts. |

## 2. Authoritative Source Registry (35 Harvested Endpoints)

Sources are ranked into four authority tiers used to prioritize Tier-1 primary agency metadata over secondary cloud mirrors during cross-catalogue canonical merging (`source_authority_rank`):
- **Tier 1A (`01`–`11`)**: European Union & Copernicus primary operational authorities, Federated DIAS/HDA gateways, and EU agencies.
- **Tier 1B (`12`–`15`)**: International EO coordinating frameworks, ECV/requirement registries, and multi-agency federated gateways.
- **Tier 1C (`16`–`22`, `30`–`33`, `35`)**: Global, national, and regional space-agency & EO datacube primary catalogues.
- **Tier 2 (`23`–`26`, `34`)** & **Tier 3 (`27`–`29`)**: Authoritative thematic/academic consortia, UN geospatial registries, and cloud data catalogues.

## 3. Reproducibility Principles
1. **Primary API Provenance**: All records originate from official REST, STAC, CSW, Elasticsearch, or DCAT-AP endpoints with zero reliance on static third-party CSV/TSV dumps.
2. **Producer-Origin & Two-Layer Institutional Attribution**: Dataset ownership (`provider_pool`: `copernicus_services`, `eu_non_copernicus`, `non_eu`) follows the originating producing institution under Regulation (EU) 2021/696 (EU-27, EEA Participating States Norway & Iceland, UK Copernicus Association effective 2024-01-01, and European space/meteorological IGOs ESA/EUMETSAT/ECMWF; third countries—including ESA member Switzerland outside Copernicus association and ESA Associate Member Canada—plus UN/global bodies sit in `non_eu`), paired with `provider_jurisdiction_tier` for policy sensitivity analysis.
3. **Missing Metadata Preserved as Null**: Missing native structured attributes (`spatial_resolution_raw`, `temporal_resolution_raw`, `temporal_start_raw`, `temporal_end_raw`, `bbox_raw`, `platform_sensor_raw`, `doi`) remain `null` and are audited transparently in [`03_harmonization/schema_completeness_report.csv`](../03_harmonization/schema_completeness_report.csv); text-extracted spatial, cadence, or coverage cues are isolated in provenance-tagged fields rather than overwriting upstream values.
4. **High-Recall Canonical Merging**: Deduplication matches exact normalized DOIs or identical pool-and-full-title slugs (`canonical_product_key`), intentionally prioritizing high recall so candidate evaluation and finer de-duplication can be performed cleanly per downstream use case.

Scope, Provenance & Interpretation Limits

This interface displays the 38,567 canonical catalogue records deduplicated conservatively from 39,202 harvested Level-3 and Level-4 records across 31 primary and federated metadata portals.

  • High recall over precision: Unlinked cross-platform cloud mirrors lacking shared DOIs, versioned releases, multi-level agency collections, and tagged sensitivity datasets (Strict EO = false, covering hybrid grids, gridded in-situ interpolations, bottom-up inventories, and reference boundaries) remain visible unless filtered out.
  • Missing upstream metadata preserved: Upstream APIs frequently omit processing levels (73.5% unlabelled in canonical), native pixel spacing (72.0% absent in adjudicated/raw grid), platform metadata (49.21% unassessed), or DOIs (67.6% absent). Missing values stay null and are never fabricated; pair text search with structured filters.
  • Sentinel attribution: Separates verified Sentinel lineage (confirmed_input_mission, retrospective_or_mixed_epoch_series) from explicit_non_sentinel, target-grid-only references (e.g., Landsat HLSL30), and unassessed_no_platform_metadata.
  • Harvest & evaluation scope: Automated checks verify 24 structural suites, 25 QA assertions, 77/77 checked EU policy product families, 40/40 GCOS ECV groups, and 79/79 curated product verification cases. On-demand mapping activations (CEMS Rapid Mapping), restricted security/commercial archives, instantaneous L2 event streams (e.g., MTG FCI Active Fire L2), and portals without open collection APIs sit outside this harvest; worldwide exhaustiveness is unmeasured.

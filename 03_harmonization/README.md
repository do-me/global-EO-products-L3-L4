# `03_harmonization` — Unified L3/L4 Schema & Harmonized Catalogue

## Purpose
Harmonizes all 34 prepared Earth Observation (EO) L3/L4 product sources (`40,118` records) from `../02_preparation/data/` into a unified, reproducible strict-RFC-8259 metadata schema (`78` record columns; `80` canonical columns) with two-layer producer-origin institutional attribution (`provider_pool` + `provider_jurisdiction_tier`), processing-level ontology and provenance classes (supporting `Level 3C`/`3U`/`3P`/`4A-D` sublevels cleanly while keeping unlabelled/conflicted entries `null` via `processing_level_conflict`), Sentinel-dependency lineage indicators (`confirmed_input_mission`, `retrospective_or_mixed_epoch_series`, `target_grid_or_harmonization_reference_only`, `explicit_non_sentinel`, `unassessed_no_platform_metadata`, keeping `asset_type_raw` separated from `platform_sensor_raw` and stratifying `sentinel_lineage_status` in `provider_pool_and_sentinel_summary.csv`), separated prose-extraction provenance (`prose_spatial_*`, `prose_cadence_*`, `spatial_footprint_meters`, `temporal_cadence_by_epoch` vs. `variable_dependent_multi_cadence`, `temporal_span_provenance`, `geographic_coverage_provenance`, `observation_domain_mask`), antimeridian crossing preservation (`bbox_crosses_antimeridian`) and single-hemisphere restrictions (`northern_hemisphere_only` across sibling DOIs), DOI provenance (`doi_source`, `doi_relation_type`, `related_dois`, blocking `describedby` promotions), harvest-date-anchored operational maturity (`01_raw/*/last_access.txt`), an explicit evidence-backed sub-product variant table (`eo_l3_l4_product_variants.parquet`, `60` rows, `19` columns), and conservative canonical deduplication.

## How to Run
```bash
uv run 03_harmonization/harmonize_catalogue.py
```

## Harmonized Schema
| Column | Type | Description |
| :--- | :--- | :--- |
| `record_id` | `string` | Unique source-qualified record identifier (`<source_catalogue>::<raw_id>`). |
| `canonical_product_key` | `string` | Cross-catalogue deduplication key (normalized DOI if available, otherwise pool + full normalized title slug). |
| `source_catalogue` | `string` | Upstream source folder ID (`01_copernicus_cmems` .. `32_nrcan_ccmeo_stac`). |
| `source_authority_rank` | `int` | Authority tier (`1` = primary space agency / Copernicus service API; `5–6` = secondary cloud mirror). |
| `raw_id`, `title`, `description` | `string` | Native product identifier, title, and cleaned abstract/description. |
| `producing_institution` | `string` | Originating institution that produced the dataset (strictly separated from hosting platform). |
| `hosting_platform` | `string` | Dissemination portal or cloud data lake hosting the record (`GEE`, `Planetary Computer`, `WEkEO`, `DEDL`, `CMR`, etc.). |
| `provider_pool` | `string` | `copernicus_services` \| `eu_non_copernicus` \| `non_eu` — assigned strictly by `producing_institution` in alignment with Regulation (EU) 2021/696 (EU-27, EEA Participating States Norway & Iceland, UK Copernicus Association effective 2024-01-01, and ESA/EUMETSAT/ECMWF; third countries including non-Copernicus-associated Switzerland and ESA Associate Member Canada, plus UN/global bodies, sit in `non_eu`). |
| `provider_jurisdiction_tier` | `string` | Granular institutional tier enabling policy-boundary sensitivity analysis: `copernicus_service` \| `eu27_national_or_eu_agency` \| `european_space_met_igo` \| `copernicus_associated_state` \| `european_esa_non_copernicus_state` \| `un_or_international_body` \| `third_country_non_european`. |
| `copernicus_service` | `string \| null` | `CMEMS` \| `CLMS` \| `C3S` \| `CAMS` \| `CEMS` \| `COP_DEM` \| `null`. |
| `is_un_or_international_body` | `bool` | Flags UN and international multilateral bodies (`FAO`, `UNEP-WCMC`, `WMO`, `GEO BON`, `CGIAR`, `World Bank`) for transparent attribution filtering. |
| `processing_level_raw` | `string \| null` | Exact upstream processing level tag prior to harmonization (`null` if omitted upstream). |
| `processing_level` | `string \| null` | `L1` \| `L2` \| `L3` \| `L3; L4` \| `L4` \| `null` (retains `null` where upstream metadata lacks explicit evidence rather than defaulting unlabelled rows to `L3`). |
| `processing_levels_available` | `string \| null` | Multi-level deliverables disclosed in upstream metadata/descriptions (e.g., `L2; L3`, `L3; L4`). |
| `processing_level_provenance` | `string` | Explicit provenance of `processing_level` (`explicit_raw_metadata`, `explicit_title_or_id`, `explicit_raw_multi_level`, `explicit_description_multi_level`, `explicit_title_l4_over_raw_l3`, `provider_documented_specification`, `inferred_from_model_or_service`, `inferred_from_ard_reflectance`, `not_applicable_non_satellite_eo`, `unlabelled_no_explicit_level`). |
| `processing_level_conflict`, `processing_level_conflict_reason` | `bool`, `string \| null` | Flags conflicting level evidence across title vs. upstream metadata (e.g., `GEDI L4A` footprint table vs. collection-level `L4B`), setting `processing_level` and `adjudicated_output_grid_meters` to `null` instead of guessing. |
| `product_level_subtype` | `string` | `L3_THEMATIC_BIOPHYSICAL` \| `L4_MODEL_REANALYSIS_SYNTHESIS` \| `L3_ARD_REFLECTANCE` \| `L3_L4_MULTI_LEVEL` \| `UPSTREAM_L1_OR_L2_UNFILTERED` \| `UNLABELLED_LEVEL`. |
| `product_ontology_class` | `string` | `eo_thematic_or_biophysical` \| `eo_reanalysis_or_model` \| `eo_ard_surface_reflectance_mosaic` \| `eo_constrained_hybrid` \| `in_situ_gridded_interpolation` \| `non_eo_inventory_or_census` \| `authoritative_reference_geometry`. |
| `product_output_category` | `string` | Output thematic domain/variable category separated from input sensor descriptions. |
| `is_ard_reflectance_only` | `bool` | `True` strictly for L3 ARD surface reflectance mosaics (`HLSL30`, `MCD43A4` NBAR, `S2GM`, `LCREF`) without leaking derived biophysical indices. |
| `strict_eo_c1_eligible` | `bool` | `True` for strict satellite/model EO products; `False` for hybrid demographic/soil models, gridded in-situ interpolations, non-EO inventories, and reference boundaries. |
| `uses_sentinel_data` | `bool` | `True` if the product uses Copernicus Sentinel (`S1`, `S2`, `S3`, `S5P`, `S6`) observations as input (excludes `HLSL30` Landsat-only target-grid references, ignores storage `asset_type_raw` tokens such as `table`, and inspects structured platform metadata prior to pre-2014 suppressions). |
| `sentinel_missions` | `string \| null` | Semicolon-separated list of Sentinel missions used (`S1`, `S2`, `S3`, `S5P`, `S6`). |
| `sentinel_lineage_status` | `string` | Disambiguates `confirmed_input_mission`, `retrospective_or_mixed_epoch_series`, `target_grid_or_harmonization_reference_only` (`HLSL30`), `explicit_non_sentinel` (explicitly non-Sentinel platforms/pre-2014 sensors), and `unassessed_no_platform_metadata`. |
| `spatial_resolution_raw` | `string \| null` | Exact upstream native spatial resolution string (`null` if omitted by upstream API; never overwritten from prose). |
| `spatial_resolution_meters` | `float \| null` | Deterministically parsed from `spatial_resolution_raw` (`null` on >=10x/<=0.1x metadata conflicts or upstream omission). |
| `spatial_footprint_meters` | `float \| null` | Physical footprint/beam diameter separated from horizontal gridded spacing (e.g., `25.0 m` GEDI waveform laser footprint vs. output grid spacing). |
| `title_token_resolution_meters` | `float \| null` | Explicit resolution tokens (e.g., `10m`, `30m`, `250m`, `1km`) parsed from `title`/`raw_id` without modifying `spatial_resolution_meters`. |
| `prose_spatial_candidate_raw`, `prose_spatial_role`, `prose_spatial_evidence_sentence` | `string \| null` | Prose-extracted spatial candidate, explicit scientific role (`delivered_output_grid` vs. `input_or_downstream_mention` / `ambiguous_multiple_resolutions`), and exact source sentence (kept strictly isolated from native `spatial_resolution_raw`). |
| `spatial_resolution_conflict` | `bool` | Flags `True` when `spatial_resolution_meters` and `title_token_resolution_meters` diverge by >=10x (`null`s `spatial_resolution_meters` instead of guessing). |
| `spatial_resolution_conflict_reason` | `string \| null` | Diagnostic description of detected spatial resolution unit/metadata conflict. |
| `adjudicated_output_grid_meters` | `float \| null` | Reconciled output grid spacing when unconflicted or resolved from a cited primary DOI specification or verified delivered-grid prose sentence; `null` under unresolvable metadata/level conflict or omission. |
| `adjudicated_spatial_grid_value`, `adjudicated_spatial_grid_units`, `adjudicated_spatial_grid_axes` | `string \| null` | Structured native grid spacing, unit (`degrees` / `meters`), and axis ordering (`lon x lat` / `lat x lon`) recorded alongside cited spatial conflict adjudications. |
| `adjudicated_spatial_resolution_source`, `adjudication_source_citation` | `string \| null` | Provenance (`raw_metadata`, `title_token`, `prose_delivered_output_grid`, `cited_provider_specification`, `null`) and authoritative documentation/DOI URL backing cited level or spatial adjudications. |
| `level_variant_specifications` | `string \| null` | Semicolon-separated summary of verified multi-deliverable/epoch sub-product variants exported to `eo_l3_l4_product_variants.parquet`. |
| `temporal_resolution_raw`, `update_frequency_raw` | `string \| null` | Native upstream observation/product step vs. archive update/publication cadence (never overwritten from prose). |
| `temporal_cadence_class` | `string \| null` | `sub_daily_or_daily` \| `multi_day_or_dekadal` \| `monthly_or_seasonal` \| `annual` \| `multi_year_periodic` \| `static_or_single_epoch` \| `null`. |
| `temporal_output_cadences` | `string \| null` | Normalized output sampling step(s) (e.g., `semimonthly; 8-day`, separated from rolling compositing windows). |
| `temporal_cadence_by_epoch`, `prose_cadence_role`, `prose_cadence_evidence_sentence` | `string \| null` | Epoch-qualified cadence regimes (`1981-2000: semimonthly; 2001-present: 8-day` for `GLOBMAP LAI v3`), cadence prose role, and supporting sentence. |
| `temporal_aggregation_window_raw` | `string \| null` | Extracted rolling retrieval/compositing window (e.g., `16-day retrieval/compositing window` for `MCD43A4` daily output). |
| `temporal_start_raw`, `temporal_end_raw` | `string \| null` | Cleaned raw native temporal start/end ISO strings (`null` if omitted upstream). |
| `temporal_start_year`, `temporal_end_year`, `temporal_span_provenance` | `int \| null`, `string` | Extracted temporal span years plus explicit provenance (`native_metadata` vs. `prose_extracted_span` vs. `unlabelled_null`). |
| `is_ongoing_archive` | `bool \| null` | `True` if open-ended active series (`temporal_end_raw >= 2025` or open-ended with `end_year >= 2025` / null end date and ongoing/regular cadence), `False` if completed/planned/deprecated/not-planned (`S-NPP` `2026-11-02`/`end of mission`), release-dated without ongoing updates, or `research_or_benchmark_release`, `null` if timestamps and upstream status are omitted. |
| `operational_maturity_class` | `string` | `operational_ongoing_series` \| `completed_or_mission_bounded_release` \| `research_or_benchmark_release` \| `planned_or_preoperational` \| `deprecated_or_superseded` \| `unknown` (never assigns `operational_ongoing_series` when `is_ongoing_archive` is `null`). |
| `is_superseded_edition`, `superseded_by_record` | `bool`, `string \| null` | Identifies superseded editions (`SOCATv1.5..v2025`, closed CLMS/EEA v1 series) and links to active successor `record_id`. |
| `bbox_west`, `bbox_south`, `bbox_east`, `bbox_north`, `bbox_crosses_antimeridian` | `float \| null`, `bool` | Bounding box coordinates (`null` if omitted) plus explicit antimeridian crossing flag (`bbox_west > bbox_east`, e.g., `ZENODO:4922168` `150°E`–`90°W`). |
| `geographic_coverage_class`, `geographic_coverage_provenance` | `string \| null`, `string` | `global` \| `quasi_global` \| `hemispheric_or_pantropical` \| `europe_regional` \| `regional_or_local` \| `null` (downgrades single-sensor GEO disks and single-hemisphere nominal envelopes across shared-DOI siblings), paired with provenance. |
| `observation_domain_class`, `observation_domain_mask` | `string \| null` | Physical observation domain (`geostationary_disk_or_sector`, `northern_hemisphere_only`, `full_global_domain`, etc.) plus biome/cryosphere/ocean-ice masks (`mangrove_biome_mask`, `cryosphere_or_glacier_mask`, `ice_free_ocean_mask` on `J-OFURO3`). |
| `platform_sensor_raw`, `asset_type_raw`, `keywords` | `string \| null` | Raw platform/sensor strings (never populated with GEE `table`/`image_collection` container types), isolated storage `asset_type_raw`, and normalized upstream keyword lists. |
| `doi`, `doi_source`, `doi_relation_type`, `related_dois` | `string \| null` | Verified primary dataset DOI (`null` where unminted; never populated with `rel="describedby"` papers/inputs), its provenance, relation type, and semicolon-separated related citations/inputs. |
| `license`, `access_url` | `string \| null` | Upstream product license and role-prioritized non-image landing page URL. |

## Outputs
- `./data/eo_l3_l4_all_catalogue_records.parquet` (and strict RFC 8259 chunked `.jsonl` files) — All `40,118` harmonized L3/L4 records across all 34 product sources (`78` columns).
- `./data/eo_l3_l4_canonical_products.parquet` — `39,474` conservatively deduplicated canonical L3/L4 products (`80` columns; `611` mirror groups collapsing `644` duplicate records) prioritizing primary-agency metadata over secondary cloud mirrors.
- `./data/eo_l3_l4_product_variants.parquet` (and strict RFC 8259 `.jsonl`) — `60` explicit evidence-backed sub-product variant rows (`19` columns, adding `variant_epoch`, `variant_footprint_meters`, and `variant_evidence`) exposing component levels, cadences, formats, epochs, and variable-parameter tiers (`TCSIF v1` `L2`/`L3`, `C3S SST` `0.05° × 0.05°`, `GLOBMAP LAI v3`, `ZENODO:10815170` `monthly`/`annual`/`static`, `PML-V2.2` `V2.2a/b/c`).
- `./provider_pool_and_sentinel_summary.csv` — Breakdown of canonical products by `provider_pool`, `processing_level`, `uses_sentinel_data`, and `sentinel_lineage_status`.
- `./schema_completeness_report.csv` — Exact non-null and null counts across all `78` harmonized record columns.
